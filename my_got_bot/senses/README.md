# 👁️ SENSES (Чувства/Восприятие)

## Назначение

Модуль `senses` отвечает за **обработку входных данных** от пользователя. Это первый этап в пайплайне бота - аналог человеческого восприятия через органы чувств.

---

## 📂 Структура

```
senses/
├── __init__.py          # Экспорты модуля
├── inbox.py             # Текстовый ввод
├── eyes.py              # Мультимодальная обработка
└── README.md            # Эта документация
```

---

## 🔑 Ключевые файлы

### 📥 `inbox.py` - Приём текстовых сообщений

**Ответственность:**
- Валидация пользовательского ввода
- Проверка команд выхода (`exit`, `quit`, `q`, `выход`)
- Фильтрация пустых сообщений

**Основная функция:**
```python
def get_user_message() -> str | None
```

**Возвращает:**
- `str` - Валидное сообщение пользователя
- `None` - Команда выхода
- `""` - Пустой ввод (игнорируется)

**Пример:**
```python
from senses.inbox import get_user_message

message = get_user_message()
if message is None:
    print("Пользователь вышел")
elif message:
    print(f"Получено: {message}")
```

---

### 👁️ `eyes.py` - Мультимодальная обработка

**Ответственность:**
- Обработка изображений (PNG, JPG, GIF, BMP, WEBP)
- Извлечение текста из PDF документов
- Извлечение текста из DOCX файлов
- Чтение обычных текстовых файлов
- Конвертация в формат для Together.ai Vision API

**Основная функция:**
```python
def process_visual_content(input_data: Union[str, Path]) -> List[Dict]
```

**Поддерживаемые форматы:**
- 🖼️ **Изображения**: `.png`, `.jpg`, `.jpeg`, `.gif`, `.bmp`, `.webp`
- 📄 **Документы**: `.pdf`, `.docx`, `.txt`
- 💬 **Текст**: Обычные строки

**Возвращает:**
```python
[
    {
        "type": "text",
        "text": "Содержимое сообщения"
    },
    {
        "type": "image_url",
        "image_url": {
            "url": "data:image/jpeg;base64,..."
        }
    }
]
```

**Пример:**
```python
from senses.eyes import process_visual_content

# Обработка текста
content = process_visual_content("Привет!")

# Обработка изображения
content = process_visual_content("/path/to/image.png")

# Обработка PDF
content = process_visual_content("/path/to/document.pdf")
```

**Технические детали:**
- Изображения конвертируются в base64 data URLs
- PDF обрабатывается через `pymupdf` (fitz)
- DOCX обрабатывается через `python-docx`
- Максимальный размер файла: Ограничен API Together.ai

## ⚙️ Как это работает

### Алгоритм обработки входа

```
Пользователь вводит данные
        ↓
[inbox.py] Валидация текста
        ↓
    Команда выхода? → YES → Возврат None
        ↓ NO
    Пустая строка? → YES → Возврат ""
        ↓ NO
    Валидный текст
        ↓
[eyes.py] Определение типа
        ↓
    ┌───────┴───────┐
    ↓               ↓
Текст         Файл (путь)
    ↓               ↓
Возврат      Определить формат
[{"type":"text"}]   ↓
              ┌─────┼─────┐
              ↓     ↓     ↓
           Image  PDF  DOCX
              ↓     ↓     ↓
          base64  Text  Text
              ↓     ↓     ↓
         Возврат массива контента
```

## 🔌 Интеграция с остальной системой

**Вызывается из:**
- `main.py` - Консольный интерфейс
- `app_chainlit.py` - Веб-интерфейс

**Передаёт данные в:**
- `engine/` - Модуль рассуждений
- `memory/` - Система памяти

**Формат выхода:**
Список словарей, совместимый с Together.ai Chat Completions API
