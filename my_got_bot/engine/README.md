# 🧠 ENGINE (Движок рассуждений)

## Назначение

Модуль `engine` - это **мозг бота**, отвечающий за рассуждения и генерацию ответов. Реализует итеративный Chain-of-Thought (CoT) подход с использованием LLM через Together.ai API.


## 🔑 Ключевые файлы

### ⚙️ `engine.py` - API вызовы и промпт-менеджмент

**Ответственность:**
- Загрузка промптов из файлов
- Формирование запросов к Together.ai API
- Обработка мультимодального контента
- Подстановка контекста (история, память, CoT)
- Обработка ошибок API

**Основные функции:**

#### `load_prompt(filename: str) -> str`
Загружает промпт из `../prompts/` директории.

```python
prompt = load_prompt("cot_initial.txt")
```

#### `think_one_step(...) -> str`
Выполняет одну итерацию Chain-of-Thought размышлений.

**Параметры:**
```python
def think_one_step(
    user_message: Union[str, List[Dict]],  # Текст или мультимодальный контент
    history: str,                           # Краткосрочная история (20 обменов)
    current_cot: str,                       # Текущая цепочка мыслей
    relevant_context: str = "",             # Релевантные прошлые разговоры
    is_first_step: bool = True              # Первая итерация?
) -> str
```

**Возвращает:**
Ответ модели (один шаг размышлений или финальный ответ с `FINAL_ANSWER:`)

**Пример:**
```python
from engine import think_one_step

response = think_one_step(
    user_message="Что такое Python?",
    history="User: Привет\nAssistant: Здравствуйте!",
    current_cot="",
    relevant_context="",
    is_first_step=True
)
```

**Технические детали:**
- Модель: `meta-llama/Llama-4-Maverick-17B-128E-Instruct-FP8`
- API: Together.ai Chat Completions
- Temperature: 0.7
- Max tokens: 1024
- Supports multimodal content (text + images)

### 🧠 `brain.py` - Хранение цепочки мыслей

**Ответственность:**
- Накопление шагов Chain-of-Thought
- Форматирование цепочки для отображения
- Очистка состояния между запросами

**Класс: `BrainText`**

```python
class BrainText:
    def __init__(self):
        """Инициализирует пустую цепочку мыслей"""
    
    def add_step(self, thought: str):
        """Добавляет один шаг размышлений"""
    
    def get_chain(self) -> str:
        """Возвращает всю цепочку как строку"""
    
    def clear(self):
        """Очищает цепочку (сброс)"""
    
    def display(self):
        """Выводит цепочку в консоль с форматированием"""
```

**Пример:**
```python
from engine import BrainText

brain = BrainText()
brain.add_step("Шаг 1: Понять вопрос")
brain.add_step("Шаг 2: Проанализировать контекст")
brain.display()  # Выводит красиво оформленную цепочку
chain = brain.get_chain()  # Получить как строку
brain.clear()  # Очистить для нового запроса
```

## ⚙️ Как это работает

### Алгоритм Chain-of-Thought (до 4 итераций)

```
Вход: user_message, history, relevant_context
        ↓
[Итерация 1] is_first_step=True
        ↓
    load_prompt("cot_initial.txt")
        ↓
    Подставить контекст:
    - История (20 обменов)
    - Релевантные прошлые разговоры
    - Сообщение пользователя
        ↓
    Отправить в Together.ai API
        ↓
    Получить ответ (response_1)
        ↓
    brain.add_step(response_1)
        ↓
    Проверить "FINAL_ANSWER:" в ответе?
        ↓
    YES → Извлечь ответ, выход
        ↓ NO
[Итерация 2-4] is_first_step=False
        ↓
    load_prompt("cot_refine.txt")
        ↓
    Подставить:
    - История
    - Релевантный контекст
    - Сообщение пользователя
    - Текущая цепочка мыслей (brain.get_chain())
        ↓
    Отправить в API
        ↓
    Получить response_N
        ↓
    brain.add_step(response_N)
        ↓
    Проверить "FINAL_ANSWER:"?
        ↓
    YES → Выход
    NO → Следующая итерация (макс 4)
        ↓
    После 4 итераций → Принудительный выход
```

## 📝 Промпт-инженерия

**Используемые промпты:**

1. **`cot_initial.txt`** (Первая итерация)
   - Просит модель начать размышление
   - Структурирует мышление (понять → проанализировать → решить)
   - Запрашивает финальный ответ с маркером `FINAL_ANSWER:`

2. **`cot_refine.txt`** (Итерации 2-4)
   - Уточняет предыдущие мысли
   - Добавляет самокритику
   - Развивает рассуждение или даёт финальный ответ

**Переменные в промптах:**
- `{relevant_context}` - Похожие прошлые разговоры
- `{history}` - Последние 20 обменов
- `{user_message}` - Текущий вопрос
- `{current_cot}` - Цепочка мыслей (для refine)

## 🔬 Стратегии рассуждений

### Текущая: Chain-of-Thought (Linear)

Последовательное углубление в одну ветку мышления.

**Преимущества:**
- Простота реализации
- Стабильные результаты
- Низкая латентность

**Недостатки:**
- Не исследует альтернативы
- Может застрять в одном направлении

### Будущая: Tree-of-Thoughts (GoT)

Разветвлённое исследование множества путей (см. `archive/brain_graph_old.py`)

**Преимущества:**
- Исследует альтернативы
- Лучшее качество ответов
- Самокоррекция

**Недостатки:**
- Выше латентность
- Больше API вызовов
- Сложнее реализация
