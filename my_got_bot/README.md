# 🤖 Chain-of-Thought Chatbot (Together.ai) + Vector Memory

Итеративный чатбот с Chain-of-Thought рассуждениями на базе Together.ai API с долгосрочной памятью на ChromaDB.

---

## 🚀 Быстрый старт

### Три простых шага:

**Шаг 1: Установите зависимости**
```bash
pip install -r requirements.txt
```

**Шаг 2: Создайте .env файл с API ключом**
```bash
cp .env.example .env
```
Затем откройте `.env` и замените `your_api_key_here` на ваш настоящий ключ от Together.ai

📍 Получить ключ: https://api.together.xyz/settings/api-keys

**Шаг 3: Запустите!**
```bash
python main.py
```

ИЛИ используйте автоматический скрипт:
```bash
./start.sh
```

## ⚙️ Как это работает

### Архитектура "Человеческая Анатомия"

Бот построен по аналогии с восприятием и мышлением человека:

1. **👁️ SENSES (Чувства)** - Обработка входных данных
   - `inbox.py` - Получает текстовое сообщение
   - `eyes.py` - Обрабатывает изображения, PDF, DOCX файлы

2. **💾 MEMORY (Память)** - Хранение контекста
   - `chat_memory.py` - Последние 20 обменов (краткосрочная)
   - `vector_store.py` - Все прошлые разговоры (долгосрочная, ChromaDB)

3. **🧠 ENGINE (Мозг)** - Размышление
   - `brain.py` - Хранит цепочку мыслей
   - `engine.py` - Выполняет итеративное Chain-of-Thought (1-4 шага)

4. **🗣️ EXPRESSION (Выражение)** - Вывод ответа
   - `mouth.py` - Извлекает финальный ответ из рассуждений

### Алгоритм работы

```
User Input → [SENSES] → [MEMORY] → [ENGINE] → [EXPRESSION] → Output
                ↓           ↓          ↓           ↓
              inbox     chat_memory  brain      mouth
              eyes      vector_store engine
```

**Полный цикл:**
1. Пользователь вводит сообщение (через `inbox` или Chainlit)
2. `eyes` обрабатывает мультимодальный контент (текст/изображения/документы)
3. `chat_memory` загружает последние 20 обменов
4. `vector_store` находит похожие прошлые разговоры через семантический поиск
5. `engine` выполняет 1-4 итерации Chain-of-Thought с моделью Llama-4-Maverick
6. `brain` хранит цепочку рассуждений
7. `mouth` извлекает `FINAL_ANSWER:` и показывает пользователю
8. Обмен сохраняется в обе памяти (краткосрочную + долгосрочную)

### Будущие улучшения 🚀

#### 🌳 Tree-of-Thoughts (GoT) Integration

**Статус:** Код готов, находится в `archive/brain_graph_old.py`

**Что это:**
Tree-of-Thoughts (ToT) - это продвинутая стратегия рассуждений, где модель исследует **множество веток мышления** параллельно, оценивает их и выбирает лучший путь.

**Отличия от текущего Chain-of-Thought:**

| Аспект | Chain-of-Thought (текущий) | Tree-of-Thoughts (будущий) |
|--------|---------------------------|---------------------------|
| **Структура** | Линейная цепочка | Древовидный граф |
| **Исследование** | Один путь | Множество веток |
| **Оценка** | Последовательная | Параллельная с scoring |
| **Самокоррекция** | Ограниченная | Активная (pruning) |
| **Качество** | Хорошее | Отличное |
| **Латентность** | Низкая (2-3 итерации) | Средняя (больше API вызовов) |

**Визуализация:**

```
Chain-of-Thought (Linear):
[Вопрос] → [Мысль 1] → [Мысль 2] → [Мысль 3] → [Ответ]

Tree-of-Thoughts (Branching):
                    ┌─ [Мысль 1.1] ─── [Мысль 1.1.1] ★ Выбрано
        ┌─ [Ветка 1] ─┤
        │           └─ [Мысль 1.2] ─── [Мысль 1.2.1]
[Вопрос]│
        │           ┌─ [Мысль 2.1] ─── [Мысль 2.1.1]
        └─ [Ветка 2] ─┤
                    └─ [Мысль 2.2] ─── [Мысль 2.2.1]
```

**Как будет работать:**

1. **Генерация веток** - На каждом шаге создаётся 2-3 альтернативных мысли
2. **Scoring** - Каждая мысль оценивается (0.0-1.0)
3. **Pruning** - Низкокачественные ветки отсекаются
4. **Best path** - Выбирается лучший путь через дерево
5. **Final answer** - Извлекается из лучшей ветки

**Реализация в `brain_graph_old.py`:**

**Когда включать GoT:**
- Сложные вопросы, требующие глубокого анализа
- Задачи с множественными решениями
- Креативные задачи (написание кода, эссе)
- Математические доказательства

**Когда использовать простой CoT:**
- Простые вопросы
- Быстрые ответы
- Ограниченный API budget
