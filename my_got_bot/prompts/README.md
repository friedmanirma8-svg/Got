# 📝 PROMPTS (Шаблоны промптов)

## Назначение

Директория `prompts` содержит **текстовые шаблоны промптов** для Chain-of-Thought рассуждений. Промпты хранятся отдельно от кода для удобства редактирования и версионирования.

---

## 📂 Структура

```
prompts/
├── cot_initial.txt      # Промпт для первой итерации
├── cot_refine.txt       # Промпт для итераций 2-4
├── archive/             # Архив старых версий
│   ├── cot_initial_v1.txt
│   └── cot_refine_v1.txt
└── README.md            # Эта документация
```

## 🔑 Активные промпты

### 🎯 `cot_initial.txt` - Первая итерация

**Назначение:**
Запускает процесс Chain-of-Thought размышлений для нового вопроса пользователя.

**Когда используется:**
- Первая итерация (iteration = 1)
- Когда `is_first_step = True` в `engine.think_one_step()`

**Структура промпта:**
1. **Роль и инструкции** - Кто ты, как мыслить
2. **Контекст:**
   - `{relevant_context}` - Похожие прошлые разговоры из векторной памяти
   - `{history}` - Последние 20 обменов из краткосрочной памяти
3. **Текущий вопрос:** `{user_message}`
4. **Запрос действия:** Начать размышление с структурой:
   - 🎯 Понять вопрос
   - 🔍 Проанализировать контекст
   - 💡 Сформулировать ответ
   - Либо дать `FINAL_ANSWER:` сразу

**Переменные:**
- `{relevant_context}` - Релевантные прошлые разговоры
- `{history}` - История последних обменов
- `{user_message}` - Текущее сообщение пользователя

**Пример содержимого:**
```
Ты умный ассистент с возможностью пошагового размышления.

=== РЕЛЕВАНТНЫЙ КОНТЕКСТ ИЗ ПРОШЛЫХ РАЗГОВОРОВ ===
{relevant_context}

=== ИСТОРИЯ ПОСЛЕДНИХ ОБМЕНОВ ===
{history}

=== НОВЫЙ ВОПРОС ПОЛЬЗОВАТЕЛЯ ===
{user_message}

Размышляй пошагово...
```

**Ожидаемый результат:**
- Либо финальный ответ с `FINAL_ANSWER:`
- Либо первый шаг размышлений (продолжится в следующей итерации)

---

### 🔄 `cot_refine.txt` - Уточнение (итерации 2-4)

**Назначение:**
Углубляет размышление или даёт финальный ответ после первичного анализа.

**Когда используется:**
- Итерации 2, 3, 4
- Когда `is_first_step = False`
- Когда в предыдущей итерации не был дан `FINAL_ANSWER:`

**Структура промпта:**
1. **Напоминание роли**
2. **Контекст:**
   - `{relevant_context}` - Прошлые разговоры
   - `{history}` - Последние обмены
   - `{user_message}` - Исходный вопрос
   - `{current_cot}` - **Цепочка мыслей до сих пор**
3. **Запрос действия:**
   - Продолжить размышление
   - Или дать `FINAL_ANSWER:` если готов

**Дополнительные переменные:**
- `{current_cot}` - Вся цепочка размышлений из предыдущих итераций

**Пример содержимого:**
```
Продолжи размышление. Вот что ты уже обдумал:

=== ТВОИ ПРЕДЫДУЩИЕ МЫСЛИ ===
{current_cot}

=== КОНТЕКСТ ===
Релевантные разговоры: {relevant_context}
История: {history}
Вопрос: {user_message}

Теперь либо углуби анализ, либо дай FINAL_ANSWER:
```

**Ожидаемый результат:**
- Финальный ответ с `FINAL_ANSWER:` (предпочтительно)
- Или дополнительный шаг размышлений

## ⚙️ Как промпты используются

### Алгоритм загрузки

```python
# В engine/engine.py

def load_prompt(filename: str) -> str:
    """Загружает промпт из my_got_bot/prompts/"""
    prompts_dir = os.path.join(os.path.dirname(__file__), "..", "prompts")
    filepath = os.path.join(prompts_dir, filename)
    
    with open(filepath, "r", encoding="utf-8") as f:
        return f.read()
```

### Выбор промпта

```python
# В engine/engine.py, функция think_one_step()

if is_first_step:
    prompt_template = load_prompt("cot_initial.txt")
else:
    prompt_template = load_prompt("cot_refine.txt")
```

### Подстановка переменных

```python
# Форматирование промпта
final_prompt = prompt_template.format(
    relevant_context=relevant_context,
    history=history,
    user_message=user_message,
    current_cot=current_cot  # Только для refine
)
```

## 🎨 Промпт-инженерия

### Принципы хороших промптов

1. **Ясная роль**
   ```
   Ты умный ассистент, способный рассуждать пошагово.
   ```

2. **Структурированный контекст**
   ```
   === СЕКЦИЯ 1 ===
   [Данные]
   
   === СЕКЦИЯ 2 ===
   [Данные]
   ```

3. **Чёткие инструкции**
   ```
   Выполни следующие шаги:
   1. Пойми вопрос
   2. Проанализируй контекст
   3. Дай ответ с маркером FINAL_ANSWER:
   ```

4. **Примеры (few-shot)**
   ```
   Пример 1:
   Вопрос: ...
   Ответ: ...
   ```

5. **Ограничения и правила**
   ```
   - Используй только предоставленный контекст
   - Не выдумывай факты
   - Будь кратким
   ```

## 📏 Формат переменных

**Обязательные переменные:**

| Переменная | Промпт | Описание |
|-----------|--------|----------|
| `{relevant_context}` | Initial, Refine | Похожие прошлые разговоры |
| `{history}` | Initial, Refine | Последние 20 обменов |
| `{user_message}` | Initial, Refine | Текущий вопрос |
| `{current_cot}` | **Refine only** | Цепочка мыслей |

**Пример подстановки:**

До:
```
История: {history}
Вопрос: {user_message}
```

После:
```
История: User: Привет\nAssistant: Здравствуйте!
Вопрос: Как дела?
```

## ✏️ Редактирование промптов

### Как внести изменения

1. **Откройте файл** в текстовом редакторе
   ```bash
   code my_got_bot/prompts/cot_initial.txt
   ```

2. **Отредактируйте** инструкции, сохраняя переменные `{...}`

3. **Сохраните** файл

4. **Перезапустите бота** (промпты загружаются при каждом вызове)

5. **Протестируйте** новое поведение

### Сохранение версий

```bash
# Создать резервную копию
cp cot_initial.txt archive/cot_initial_v2_backup.txt

# Внести изменения
nano cot_initial.txt

# Если не понравилось - восстановить
cp archive/cot_initial_v2_backup.txt cot_initial.txt
```

## 💡 Лучшие практики

### ✅ DO (Делай)

- Используй чёткие разделители секций
- Явно указывай формат ожидаемого ответа
- Давай примеры (few-shot learning)
- Проси модель мыслить пошагово
- Используй эмодзи для структурирования

### ❌ DON'T (Не делай)

- Не делай промпт слишком длинным (> 2000 слов)
- Не давай противоречивых инструкций
- Не забывай про переменные `{...}`
- Не удаляй важные контекстные секции
- Не смешивай языки без причины
